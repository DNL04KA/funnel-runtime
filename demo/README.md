# Демо-ролик

`funnel-runtime-reel.mp4` — 2:17, обзор проекта по главам.

Это не скринкаст: ролик записывается Playwright'ом, который гоняет **настоящее
приложение в настоящем Chrome** по HTTP. Публикация версии, откат и цифры на
дашборде в кадре — реальные, не смонтированные. Карточки между сценами —
слой поверх той же страницы, поэтому переходы без мигания.

## Переснять

```bash
# 1. Подготовить данные и собрать приложение
npm run reset:db && npm run seed:versions && npm run seed:traffic -- --sessions 150
npm run build && npm start          # в отдельном терминале, :8787

# 2. Записать и собрать
cd demo && npm install
npm run record                      # → demo/reel-video/*.webm
npm run encode                      # → demo/funnel-runtime-reel.mp4
```

Нужен `ffmpeg` в `PATH` (для шага encode) и установленный Chrome.
Другой адрес — через `DEMO_BASE=https://... npm run record`.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `stage.mjs` | слой поверх приложения: полноэкранные карточки, нижняя подпись, подсветка кликов, плавный скролл |
| `reel.mjs` | сценарий: десять глав от титров до финальной карточки |
| `encode.sh` | webm → mp4 с фейдами |

## Оговорки

Ролик зависит от того, что в базе есть засеянный трафик и что активна версия
**v2** (`npm run seed:versions` оставляет активной именно её). Сценарий по ходу
публикует v3 и откатывает обратно на v2, так что база после записи
возвращается в исходное состояние.

В первой сцене вариант эксперимента зафиксирован через `?variant=A` — без
этого бэкенд назначал бы его сам, у варианта B другой порядок шагов, и
сценарий разошёлся бы с тем, что происходит на экране. Это подписано прямо в
кадре.

На macOS 12 Playwright не ставит свои бинарники (`Playwright does not support
chromium on mac12`). Обходится так: запуск на установленном Chrome
(`channel: 'chrome'`, уже прописано в `reel.mjs`) и симлинк системного ffmpeg
туда, где Playwright ищет свой:

```bash
mkdir -p ~/Library/Caches/ms-playwright/ffmpeg-1011
ln -sf "$(which ffmpeg)" ~/Library/Caches/ms-playwright/ffmpeg-1011/ffmpeg-mac
```
